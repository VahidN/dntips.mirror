‫انتشار نسخه Release Candidate 1 پلتفرم دات‌نت ۱۱ همراه با مجوز پشتیبانی محیط تولید


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۶/۱۸ ۱۰:۰۰
آدرس: www.dntips.ir
شرکت مایکروسافت از انتشار نسخه Release Candidate 1 برای .NET 11 خبر داد. این نسخه اولین نسخه نامزد انتشار است که شامل مجوز پشتیبانی برای محیط‌های تولید بوده و به توسعه‌دهندگان اجازه می‌دهد با اطمینان خاطر از آن در برنامه‌های تجاری خود استفاده کنند. این انتشار در کنار نسخه‌های جدید Visual Studio 2026 Insiders و Visual Studio Code به همراه کیت توسعه C# قابل استفاده است.
در این نسخه بهبودهای چشمگیری در بخش کتابخانه‌ها، زمان اجرا یا Runtime، و ابزارهای توسعه ارائه شده است. از جمله تغییرات مهم می‌توان به بهبودهای dotnet test برای تست برنامه‌های موبایل، قابلیت‌های جدید در MSBuild برای مدیریت آرشیوها، و بروزرسانی‌های NuGet اشاره کرد. همچنین زبان‌های C# و F# قابلیت‌های جدیدی مانند تثبیت unions و الگوهای پیشرفته‌تر را دریافت کرده‌اند.
بخش ASP.NET Core نیز با بروزرسانی‌های مهمی در حوزه‌های امنیتی، SignalR، و بهبود پشتیبانی از OpenAPI همراه بوده است. توسعه‌دهندگان می‌توانند با نصب .NET 11 SDK و استفاده از ابزارهای سازگار جدید، توسعه برنامه‌های خود را با این نسخه آغاز کنند و از عملکرد و ویژگی‌های جدید بهره‌مند شوند.
