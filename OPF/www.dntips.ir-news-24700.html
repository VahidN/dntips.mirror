‫پروژه Jigen؛ پایگاه داده وکتور توسعه‌یافته از صفر با زبان سی‌شارپ برای دات‌نت


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۷/۱۳ ۰۹:۱۵
آدرس: www.dntips.ir
پروژه Jigen یک پایگاه داده وکتور است که از ابتدا به زبان C# و به طور ویژه برای پلتفرم .NET طراحی و پیاده‌سازی شده است. هدف از توسعه این پروژه، فراهم کردن امکان جستجوی وکتور به صورت درون‌برنامه یا in-process درست مانند عملکرد پایگاه داده SQLite در داخل برنامه‌ها و همچنین به صورت سرور مستقل است.
این پایگاه داده از فناوری‌های مدرن اکوسیستم دات‌نت شامل .NET 8 و .NET 10، ASP.NET Core و gRPC بهره می‌برد. همچنین قابلیت تولید امبدینگ متن در این سامانه به کمک ONNX Runtime به صورت توکار فراهم شده است که انعطاف‌پذیری بالایی را به همراه دارد.
معماری و لایه ذخیره‌سازی این پروژه به عنوان یک ابتکار پژوهشی شکل گرفته است تا میزان کارایی و عملکرد پایگاه‌های داده نوشته شده با کدهای خالص C# ارزیابی شود. این پروژه فرصت مناسبی برای توسعه‌دهندگان فراهم می‌کند تا با جزئیات داخلی زمان اجرای .NET و ساختار پایگاه‌های داده وکتور بیشتر آشنا شوند.
