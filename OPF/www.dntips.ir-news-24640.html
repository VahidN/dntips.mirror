‫انتشار نسخه Release Candidate 1 پلتفرم دات‌نت ۱۱ همراه با مجوز پشتیبانی محیط تولید ←
عنوان:

‫انتشار به‌روزرسانی‌های امنیتی و سرویس‌ریلیزهای شهریور ماه ۱۴۰۵ برای دات‌نت و دات‌نت فریم‌ورک


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۶/۱۸ ۱۰:۰۰
آدرس: www.dntips.ir
شرکت مایکروسافت مجموعه‌ای از به‌روزرسانی‌های جدید را تحت عنوان سرویس‌ریلیزهای شهریور ماه ۱۴۰۵ برای پلتفرم‌های .NET و .NET Framework منتشر کرده است. این نسخه شامل اصلاحات مهم امنیتی و غیرامنیتی است که پایداری و امنیت برنامه‌های سازمانی را بهبود می‌بخشد. توسعه‌دهندگانی که از نسخه‌های مختلف .NET استفاده می‌کنند باید در سریع‌ترین زمان ممکن نسبت به اعمال این پچ‌ها اقدام نمایند.
در این به‌روزرسانی چندین آسیب‌پذیری امنیتی مهم با شناسه‌های CVE برطرف شده‌اند که نسخه‌های مختلف از جمله .NET 10.0، .NET 9.0 و .NET 8.0 را تحت تأثیر قرار می‌دادند. همچنین برخی از آسیب‌پذیری‌های گزارش شده مربوط به نسخه‌های قدیمی‌تر .NET Framework نیز در این بسته اصلاح شده‌اند. این اقدامات بخشی از تلاش مداوم مایکروسافت برای ارتقای امنیت زیرساخت‌های نرم‌افزاری است.
توسعه‌دهندگان می‌توانند بسته‌های نصبی جدید، باینری‌ها و تصاویر کانتینر را از طریق کانال‌های رسمی دریافت کنند. به‌روزرسانی اجزای مختلفی نظیر ASP.NET Core و Entity Framework Core نیز در این انتشار گنجانده شده است. بررسی یادداشت‌های انتشار و اعمال به‌روزرسانی‌های جدید برای حفظ امنیت برنامه‌ها و سرویس‌های مستقر در محیط‌های تولیدی اکیداً توصیه می‌شود.
