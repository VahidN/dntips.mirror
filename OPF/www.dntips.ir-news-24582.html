‫انتشار به‌روزرسانی‌های امنیتی و سرویس‌دهی .NET و .NET Framework برای اوت ۲۰۲۶


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۵/۲۱ ۰۸:۱۵
آدرس: www.dntips.ir
مایکروسافت به‌روزرسانی‌های سرویس‌دهی ماه اوت ۲۰۲۶ را برای پلتفرم‌های .NET و .NET Framework منتشر کرد. این نسخه‌های جدید شامل مجموعه‌ای از اصلاحات امنیتی و غیرامنیتی هستند که برای بهبود پایداری و امنیت سیستم‌ها ارائه شده‌اند.
این به‌روزرسانی‌ها نسخه‌های .NET 10.0 (نسخه 10.0.11)، .NET 9.0 (نسخه 9.0.19) و .NET 8.0 (نسخه 8.0.30) را هدف قرار می‌دهند. در این انتشار، چندین آسیب‌پذیری بحرانی از جمله اجرای کد از راه دور و ارتقای سطح دسترسی برطرف شده‌اند که در قالب چندین CVE شناسایی شده بودند.
اصلاحات اعمال شده در این ماه، تمامی اجزای کلیدی از جمله ASP.NET Core و Entity Framework Core و همچنین محیط زمان اجرای یا همان Runtime را شامل می‌شود. توسعه‌دهندگان باید برای رفع این آسیب‌پذیری‌ها، محیط‌های توسعه و عملیاتی خود را سریعاً به آخرین نسخه‌ها ارتقا دهند.
علاوه بر این، به‌روزرسانی‌های جدیدی برای .NET Framework نیز منتشر شده است که شامل رفع باگ‌های امنیتی و بهبودهای عملکردی است. جزئیات بیشتر و یادداشت‌های انتشار برای هر یک از این نسخه‌ها در مستندات رسمی مایکروسافت در دسترس است.
