‫پروژه Scribble؛ وایت‌برد نامحدود و چندسکویی توسعه‌یافته با دات‌نت و Avalonia UI


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۷/۱۳ ۰۹:۰۱
آدرس: www.dntips.ir
پروژه منبع‌باز Scribble یک وایت‌برد نامحدود و چندسکویی است که با استفاده از تکنولوژی‌های مدرن اکوسیستم .NET پیاده‌سازی شده است. این ابزار به کاربران اجازه می‌دهد روی پلتفرم‌های مختلف به صورت مشارکتی به طراحی و یادداشت‌برداری بپردازند.
در ساخت این پروژه از فریم‌ورک Avalonia UI برای ایجاد یک رابط کاربری یکپارچه و چندسکویی استفاده شده است. همچنین رندرینگ گرافیکی آن توسط کتابخانه SkiaSharp مدیریت می‌شود که کارایی بالایی در ترسیم گرافیک‌های دوبعدی ارائه می‌دهد.
برای پشتیبانی از قابلیت رسم مشارکتی و هم‌زمان، این سیستم از SignalR بهره می‌برد که ارتباط Real-Time را میان کلاینت و سرور برقرار می‌کند. توسعه‌دهندگان C# و .NET می‌توانند از این پروژه به عنوان یک نمونه عملی برای ساخت برنامه‌های دسکتاپ و تحت شبکه مقیاس‌پذیر استفاده کنند.
