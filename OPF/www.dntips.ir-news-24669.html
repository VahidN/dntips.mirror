یک کامپوننت Responsive با قابلیت‌های زیر:
- تقویم هجری شمسی / جلالی با رابط فارسی
- تقویم هجری قمری با رابط عربی
- تقویم میلادی با رابط و اعداد انگلیسی
- پشتیبانی از React JavaScript و TypeScript
- ورودی قابل تایپ و همگام‌سازی لحظه‌ای با تقویم
- فرمت‌های عددی و نوشتاری مختلف
- انتخاب فوری یا استفاده از دکمه‌های تأیید و انصراف
- امکان غیرفعال‌کردن بازه‌های تاریخی
- شخصی‌سازی عنوان‌ها، متن دکمه‌ها و فونت
- طراحی Responsive برای موبایل، تبلت و دسکتاپ
- قابل استفاده روی Input، Button، Span و عناصر سفارشی
