‫معرفی Shiny.Net.HttpServer؛ سرور HTTP سبک برای محیط‌هایی که ASP.NET Core در آن‌ها اجرا نمی‌شود


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۵/۲۲ ۰۸:۰۰
آدرس: www.dntips.ir
Allan Ritchie کتابخانه جدیدی به نام Shiny.Net.HttpServer را معرفی کرده است که یک سرور HTTP واقعی و مستقل است. این ابزار برای محیط‌هایی طراحی شده است که ASP.NET Core به دلیل وابستگی به Microsoft.AspNetCore.App قادر به اجرا در آن‌ها نیست، مانند اپلیکیشن‌های .NET MAUI در سیستم‌عامل iOS.
این کتابخانه با هدف کاهش وابستگی‌ها توسعه یافته و تنها از Microsoft.Extensions.* استفاده می‌کند. برای جلوگیری از مشکلات مربوط به Trim و AOT در محیط‌های موبایل، پیاده‌سازی‌های داخلی برای JSON (با استفاده از System.Text.Json)، توکن‌های JWT و پروتکل‌های HTTP/2 و HTTP/3 در نظر گرفته شده است.
ساختار این سرور بر اساس چهار سطح (Tier) طراحی شده است تا انعطاف‌پذیری لازم را فراهم کند. این سطوح از یک تابع ساده برای پاسخ به درخواست‌ها شروع شده و تا سیستم‌های مسیریابی (Routing) و میان‌افزارهای (Middleware) مشابه ASP.NET Core گسترش می‌یابند.
تمرکز اصلی این پروژه بر سازگاری کامل با AOT و Single-file است تا توسعه‌دهندگان بتوانند بدون نگرانی از خطاهای زمان اجرا در محیط‌های محدود، سرورهای HTTP را روی دستگاه‌های موبایل یا سخت‌افزارهایی مانند Raspberry Pi اجرا کنند.
