‫معرفی کتابخانه StringExtension برای مدیریت بهینه رشته‌ها در C#


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۵/۱۹ ۰۹:۴۶
آدرس: www.dntips.ir
کتابخانه StringExtension یک ابزار جدید برای زبان C# است که مجموعه‌ای از متدهای کاربردی جهت مدیریت و دستکاری رشته‌ها را ارائه می‌دهد. این کتابخانه بر سه اصل اساسی یعنی صحت عملکرد، کارایی بالا و داشتن یک سطح API مینیمال تمرکز دارد.
از نظر فنی، این ابزار برای کاهش تخصیص حافظه یا Zero-allocation طراحی شده است. اکثر متدها در لایه‌های داخلی از Span و ReadOnlySpan استفاده می‌کنند و برای مدیریت ورودی‌ها، بسته به اندازه آن‌ها از stackalloc یا ArrayPool بهره می‌برند تا از تخصیص‌های مکرر حافظه جلوگیری شود.
یکی از ویژگی‌های برجسته این کتابخانه، پشتیبانی کامل و صحیح از استاندارد Unicode است. متدهای طبقه‌بندی و مقایسه کاراکترها به جای استفاده از واحدهای کد UTF-16، از Rune استفاده می‌کنند تا کاراکترهای خارج از صفحه چندزبانه پایه مانند ایموجی‌ها به درستی پردازش شوند.
این کتابخانه برای هر متدی که ورودی string می‌پذیرد، یک نسخه جایگزین با ReadOnlySpan ارائه داده است تا امکان کار با برش‌های رشته بدون تخصیص حافظه میسر شود. لازم به ذکر است که پیش‌نیاز استفاده از این کتابخانه، نصب .NET 10.0 یا نسخه‌های جدیدتر است.
