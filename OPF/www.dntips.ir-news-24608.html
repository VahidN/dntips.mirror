‫معرفی polyglot-sql-net؛ رابط .NET برای تبدیل‌کننده SQL نوشته شده با Rust


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۶/۰۱ ۰۹:۱۵
آدرس: www.dntips.ir
کتابخانه polyglot-sql-net به عنوان یک Wrapper مبتنی بر FFI برای ابزار Polyglot معرفی شده است. این ابزار که با زبان Rust توسعه یافته، امکان تجزیه، قالب‌بندی و ترجمه بین بیش از ۳۰ گویش مختلف SQL را فراهم می‌کند.
این پروژه با هدف ارائه عملکرد بالا در تولید درخت نحو انتزاعی (AST) و تبدیل کدهای SQL طراحی شده است. توسعه‌دهندگان می‌توانند با استفاده از این رابط، قدرت پردازش زبان Rust را در پروژه‌های .NET خود به کار بگیرند.
برای پیاده‌سازی، دو بسته nuget تحت عناوین PolyglotSql.Core و PolyglotSql.Bundle در دسترس است. بسته اول برای مدیریت دستی کتابخانه‌های نیتیو و بسته دوم برای استفاده سریع با باینری‌های پیش‌فرض ویندوز و لینوکس ارائه شده است.
