‫عامل سفارشی WinForms Expert مخصوص توسعه رابط کاربری دسکتاپ با Windows Forms


نویسنده: وحید نصیری
تاریخ: ۱۴۰۵/۰۵/۳۰ ۰۸:۳۲
آدرس: www.dntips.ir
مایکروسافت و گیت‌هاب اولین عوامل سفارشی (Custom Agents) متمرکز بر دات‌نت را به اکوسیستم GitHub Copilot اضافه کردند: C# Expert و WinForms Expert. این عوامل به‌صورت فایل‌های Markdown دستورالعمل ارائه شده‌اند و برای افزایش بهره‌وری و کیفیت کد طراحی شده‌اند.
C# Expert بر بهترین شیوه‌های مدرن سی‌شارپ تمرکز دارد؛ قراردادهای پروژه را رعایت می‌کند، کدهای غیرضروری (مثل اینترفیس یا پارامترهای بلااستفاده) را به حداقل می‌رساند، الگوهای async/await را با مدیریت صحیح cancellation و exception پیاده می‌کند و از تست‌های رفتارمحور و یکپارچگی پشتیبانی می‌کند.
WinForms Expert مخصوص توسعه رابط کاربری دسکتاپ با Windows Forms است. الگوهای رایج مثل MVVM و MVP را پوشش می‌دهد، به wiring رویدادها و مدیریت state کمک می‌کند و مهم‌تر از همه، از تغییر ناخواسته فایل‌های .Designer.cs جلوگیری می‌کند تا طراح ویژوال استودیو خراب نشود (یکی از مشکلات رایج ابزارهای تولید کد).
برای استفاده، فایل‌های CSharpExpert.agent.md و WinFormsExpert.agent.md را از مخزن awesome-copilot گیت‌هاب دانلود کرده و در پوشه .github/agents پروژه قرار دهید. سپس می‌توانید در GitHub (برای تخصیص issueها)، VS Code Insiders یا نسخه‌های آزمایشی Visual Studio از آن‌ها استفاده کنید. پشتیبانی از دستور /agent در Copilot CLI نیز در آینده اضافه خواهد شد.
این عوامل هنوز در مرحله آزمایشی هستند و مایکروسافت در حال جمع‌آوری بازخورد است. از نوامبر، Visual Studio 2022 Insiders (نسخه ۱۷.۱۴.۲۱) با فعال‌سازی feature flag مربوطه می‌تواند به‌صورت خودکار عامل مناسب را به پروژه متصل کند.
این حرکت، گامی مهم برای توسعه‌دهندگان سی‌شارپ و WinForms است تا از راهنمایی‌های تخصصی‌تر و ایمن‌تر Copilot بهره‌مند شوند.
