‫معرفی پروژه LegacyBlazorJs برای پشتیبانی Blazor Server از مرورگرهای قدیمی


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۵/۰۴ ۰۸:۱۶
آدرس: www.dntips.ir
پروژه LegacyBlazorJs با هدف گسترش پشتیبانی Blazor Server برای مرورگرهای قدیمی‌تر توسعه یافته است. این ابزار فایل رسمی blazor.web.js مربوط به ASP.NET Core را برای اهداف مختلف زبان جاوااسکریپت بازسازی می‌کند.
در حالت پیش‌فرض، پشتیبانی مرورگری در ASP.NET Core تنها برای مرورگرهای به‌روز یا همان evergreen در نظر گرفته شده است. این پروژه با ارائه یک بسته NuGet در قالب Razor Class Library این محدودیت را برطرف کرده و امکان اجرای برنامه‌ها در محیط‌های قدیمی‌تر را فراهم می‌سازد.
این ابزار به طور خودکار به‌روزرسانی‌ها را ساخته، تست کرده و منتشر می‌کند تا با نسخه‌های جدید سازگار بماند. توسعه‌دهندگان Blazor می‌توانند از این راهکار برای دسترسی کاربران با مرورگرهای قدیمی به اپلیکیشن‌های خود استفاده کنند.
