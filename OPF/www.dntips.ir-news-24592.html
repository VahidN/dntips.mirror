‫معرفی بایندینگ‌های .NET 8 برای موتور تولید PDF Fullbleed


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۵/۲۷ ۱۴:۳۰
آدرس: www.dntips.ir
پروژه fullbleed-dotnet بایندینگ‌های idiomatic برای .NET 8 ارائه می‌دهد که به توسعه‌دهندگان اجازه می‌دهد از قابلیت‌های موتور PDF Fullbleed استفاده کنند. این ابزار برای رندرینگ قطعی HTML و CSS به PDF و همچنین انتشار داده‌های متغیر (VDP) طراحی شده است.
این کتابخانه از دو لایه یکپارچه‌سازی متفاوت تشکیل شده است. لایه FullBleedEngine با استفاده از یک C ABI امن، مستقیماً با موتور نوشته شده به زبان Rust ارتباط برقرار می‌کند و برای رندرینگ در حافظه و پردازش‌های دسته‌ای با حجم بالا ایده‌آل است.
در مقابل، لایه FullBleedCliClient از طریق APIهای مدیریت پروسه و ساختار JSON با دستورات خط فرمان fullbleed تعامل دارد. این رویکرد برای مواردی نظیر شناسایی ابزارها در زمان اجرا، اعتبارسنجی پروفایل‌ها و مدیریت اسکلت‌بندی پروژه‌ها کاربرد دارد.
