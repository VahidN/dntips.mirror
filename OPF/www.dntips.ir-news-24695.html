‫انتشار ابزار jsreport-dotnet برای استفاده از قابلیت‌های گزارش‌گیری در دات‌نت


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۷/۱۳ ۰۸:۴۵
آدرس: www.dntips.ir
مخزن رسمی jsreport-dotnet ابزاری کاربردی برای توسعه‌دهندگان ASP.NET Core و .NET فراهم می‌کند تا بتوانند قابلیت‌های پیشرفته گزارش‌گیری از جمله رندر کردن فایل‌های PDF و Excel را به صورت مستقیم درون برنامه‌های خود پیاده‌سازی کنند. این کیت توسعه نرم‌افزار شامل یک کلاینت REST مبتنی بر زبان C# برای ارتباط با سرور گزارش‌گیری و همچنین مجموعه‌ای از ابزارها برای اجرای محلی jsreport به طور مستقیم در پروژه‌های دات‌نتی است.
مستندات و نمونه‌های ارائه‌شده در این مخزن، سناریوهای مختلفی مانند استفاده از این ابزار در برنامه‌های کنسولی .NET Core، برنامه‌های وب ASP.NET Core MVC و حتی برنامه‌های سنتی .NET Framework را پوشش می‌دهند. توسعه‌دهندگان می‌توانند به راحتی با استفاده از ابزارهای کانتینرسازی مانند Docker و Docker Compose محیط‌های اجرایی خود را مدیریت کرده و jsreport را به صورت یک سرویس مجزا یا یکپارچه در معماری نرم‌افزاری خود به کار گیرند.
