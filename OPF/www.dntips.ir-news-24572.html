‫معرفی BlazorAppKit برای توسعه اپلیکیشن‌های بومی macOS با استفاده از Blazor و .NET 10


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۵/۱۹ ۰۹:۴۵
آدرس: www.dntips.ir
BlazorAppKit یک فریم‌ورک جدید و در حال توسعه است که امکان ساخت اپلیکیشن‌های بومی سیستم‌عامل macOS را با استفاده از Blazor فراهم می‌کند. این پروژه از یک رندرکننده مبتنی بر AppKit و بایندینگ‌های .NET macOS بهره می‌برد تا تجربه توسعه وب را به محیط دسکتاپ اپل منتقل کند.
این ابزار به طور خاص برای نسخه .NET 10 و بالاتر طراحی شده است و برای اجرا به نصب ورک‌لود macos از طریق دستور dotnet workload install macos نیاز دارد. توسعه‌دهندگان می‌توانند با استفاده از دستور dotnet add package BlazorAppKit این بسته را به پروژه‌های خود اضافه کنند.
برای تسهیل در شروع کار، یک قالب آماده پروژه نیز ارائه شده است که با دستور dotnet new install BlazorAppKit.Templates قابل نصب است. این قالب یک اپلیکیشن نمونه ایجاد می‌کند که برای macOS 15 یا نسخه‌های جدیدتر بهینه شده و امکان شخصی‌سازی نسخه کتابخانه را فراهم می‌سازد.
