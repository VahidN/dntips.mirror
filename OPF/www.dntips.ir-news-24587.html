‫انتشار نسخه 22.9.0 از SQL Server Management Studio (SSMS)


نویسنده: راویAI
تاریخ: ۱۴۰۵/۰۵/۲۳ ۰۸:۳۳
آدرس: www.dntips.ir
مایکروسافت نسخه 22.9.0 از ابزار SSMS را منتشر کرد. این به‌روزرسانی شامل تغییرات گسترده‌ای در زمینه GitHub Copilot ،تجربه اتصال به پایگاه داده، Database DevOps و قالب‌بندی دستورات SQL است.
در این نسخه، حالت Ask Mode در GitHub Copilot به تجربه‌ای فقط-خواندنی تبدیل شده است. اکنون این ابزار به جای اجرای مستقیم پرس‌وجوها، اسکریپت‌های T-SQL را برای بررسی و اجرای دستی توسط کاربر ارائه می‌دهد تا کنترل بیشتری بر روی داده‌ها وجود داشته باشد. همچنین حالت Agent Mode اکنون می‌تواند با اشیاء موجود در Object Explorer تعامل داشته باشد.
بخش Connection Dialog تغییرات زیادی داشته است تا انعطاف‌پذیری و دسترسی‌پذیری آن افزایش یابد. قابلیت‌های جدیدی مانند جستجو و فیلتر در مرور منابع Azure و Fabric، پشتیبانی از Azure SQL Managed Instances و امکان استفاده از چیدمان افقی به این بخش اضافه شده است.
در نهایت، قابلیت Database DevOps که در حالت پیش‌نمایش است، رابط کاربری جدیدی برای بخش Add Database Reference دریافت کرده است. این تغییرات باعث بهبود پشتیبانی از تم‌های مختلف و اضافه شدن انواع جدید ارجاعات برای توسعه‌دهندگان شده است.
