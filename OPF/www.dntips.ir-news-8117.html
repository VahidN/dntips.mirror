‫درخواست سورس باز کردن (SQL Server Compact (CE


نویسنده: وحید نصیری
تاریخ: ۱۳۹۴/۰۶/۰۶ ۱۱:۲۳
آدرس: www.dntips.ir
 SQL Server Compact یکی از گزینه‌های بسیار مناسب جهت توسعه‌ی برنامه‌های متوسط و سبک است. توسعه‌ی آن هم به نظر متوقف شده‌است. LocalDB نیز به علت نحوه‌ی توزیع آن نمی‌تواند جایگزینی برای SQL Server CE باشد. به همین جهت سورس باز کردن آن می‌تواند آینده‌ی آن‌را تضمین کند.
